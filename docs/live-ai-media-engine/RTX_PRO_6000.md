# RTX PRO 6000 Blackwell

Seldrune Live treats the NVIDIA RTX PRO 6000 Blackwell 96 GB class as its
preferred production accelerator.

Worker admission requires CUDA, sufficient VRAM, and the configured media
capabilities. Capacity defaults are conservative planning values, not benchmark
claims. Actual concurrent-session limits must be measured with the selected
models, resolution, frame rate, runtime and encoder.

The accelerator profile remains provider-independent. Runpod can host the first
worker while Seldrune keeps the option to route future workers to other clouds
or authorized local hardware.
